# King of Kebap Krumbach – Website & digitale Speisekarte

Statischer Entwurf (HTML/CSS/JS, ohne Build-Schritt) für den Kundentermin.
Weißer Hintergrund, Gold-Akzente, Animationen, Foto zu jedem Gericht, Suche, Kategorie-Navigation und Detailansicht.

- `index.html` – komplette Seite, Speisekarte als `CATS`-Array im Script (Stand: Faltflyer 11/2026)
- `img/` – Platzhalterfotos aus dem Faltflyer, werden später durch Magnific-Bilder ersetzt

Hosting: SiteGround (GrowBig), Upload von `index.html` + `img/` ins `public_html` der Domain.
Domain wird nach Freigabe durch den Kunden gekauft.

Gestaltung: Bdesign · Bayram Özer
